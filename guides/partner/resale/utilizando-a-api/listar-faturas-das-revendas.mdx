<Warning>
`GET /partner/v2/resales/invoices` está **descontinuado**. A data de desligamento anunciada foi 01/07/2025: hoje a rota ainda responde, com os headers `Deprecation: true` e `Sunset: Tue, 01 Jul 2025 00:00:00 GMT`, e pode ser removida a qualquer momento. Use [`GET /partner/v2/{partnerId}/resales/invoices`](/guides/partner/invoices/utilizando-a-api/listando-resales-invoices).
</Warning>

Apesar do nome, o endpoint não agrega por revenda: ele devolve **uma entrada por fatura de loja de revenda** do mês, identificada só pelo `resaleId` (não traz `merchantId`). Lojas atendidas diretamente pelo parceiro ficam de fora.

| Status | Quando |
| --- | --- |
| `200 OK` | Lista de faturas. |
| `204 No Content` | Nenhuma fatura de loja de revenda no período. |
| `403 Forbidden` | `x-partners` fora do alcance do token. |

## Requisição

<CodeGroup>
```bash cURL
curl 'https://api.deliveryvip.com.br/partner/v2/resales/invoices?year=2024&month=1' \
  --header 'Authorization: Bearer {token}'
```

```js Node.js
const response = await fetch(
  'https://api.deliveryvip.com.br/partner/v2/resales/invoices?year=2024&month=1',
  { headers: { Authorization: `Bearer ${token}` } },
)
```

```python Python
response = requests.get(
    "https://api.deliveryvip.com.br/partner/v2/resales/invoices",
    params={"year": 2024, "month": 1},
    headers={"Authorization": f"Bearer {token}"},
)
```
</CodeGroup>

<ParamField query="year" type="integer">Ano. Sem ele, vale o ano corrente.</ParamField>
<ParamField query="month" type="integer">Mês, de 1 a 12. Sem ele, vale o mês corrente.</ParamField>
<ParamField header="x-partners" type="string[]">
Restringe a parceiros ou revendas específicos, como em [Filtrar por Partners](/guides/partner/merchant/utilizando-a-api/listar-merchants#filtrar-por-partners).
</ParamField>
