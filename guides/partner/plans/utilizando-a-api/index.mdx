Os planos são só leitura pela API: crie e edite no painel do parceiro.

| Endpoint | O que faz |
| --- | --- |
| `GET /partner/v2/{partnerId}/plans` | [Listar planos](/guides/partner/plans/utilizando-a-api/listar-planos). |
| `GET /partner/v2/{partnerId}/plans/{planId}` | [Obter detalhes do plano](/guides/partner/plans/utilizando-a-api/obter-detalhes-do-plano). |
