`GET /partner/v2/{partnerId}/plans/{planId}` devolve um plano. Valem as mesmas regras de visibilidade de [Listar planos](/guides/partner/plans/utilizando-a-api/listar-planos): com o ID de uma revenda, um plano `DIRECT_MERCHANT` retorna `404`.

| Status | Quando |
| --- | --- |
| `200 OK` | O plano. |
| `403 Forbidden` | `partnerId` fora do alcance do token. |
| `404 Not Found` | Plano inexistente ou não visível para esse `partnerId`. |

<CodeGroup>
```bash cURL
curl 'https://api.deliveryvip.com.br/partner/v2/{partnerId}/plans/{planId}' \
  --header 'Authorization: Bearer {token}'
```

```js Node.js
const response = await fetch(`https://api.deliveryvip.com.br/partner/v2/${partnerId}/plans/${planId}`, {
  headers: { Authorization: `Bearer ${token}` },
})
const plan = await response.json()
```

```python Python
response = requests.get(
    f"https://api.deliveryvip.com.br/partner/v2/{partner_id}/plans/{plan_id}",
    headers={"Authorization": f"Bearer {token}"},
)
plan = response.json()
```
