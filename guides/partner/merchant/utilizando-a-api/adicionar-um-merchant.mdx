title: Cadastrar uma loja
description: Crie uma loja vinculada ao seu parceiro ou a uma das suas revendas.

`POST /partner/v2/{partnerId}/merchants` cria a loja já pronta para uso: domínio padrão, formas de pagamento, áreas de entrega e assinatura em `TRIAL` por 10 dias, no plano padrão (`standard`) do parceiro.

<Info>
O `partnerId` define a quem a loja pertence:

* **ID do parceiro**: a loja é atendida diretamente pelo parceiro.
* **ID de uma revenda**: a loja nasce na revenda (`resaleId`), abaixo do parceiro dela.

Um token de parceiro aceita o próprio ID e o de qualquer revenda dele. Um token de revenda aceita só o ID da revenda. Qualquer outro ID retorna `403`. O ID do parceiro aparece em `partnerId` nas respostas de [Listar lojas](/guides/partner/merchant/utilizando-a-api/listar-merchants).
</Info>

<Warning>
A loja recebe o plano marcado como `standard` do parceiro. Confira em [Listar planos](/guides/partner/plans/utilizando-a-api/listar-planos) se existe um plano padrão disponível antes de cadastrar.
</Warning>

## Respostas

| Status | Quando |
| --- | --- |
| `201 Created` | Loja criada. O corpo é a loja completa, no formato de [Obter detalhes](/guides/partner/merchant/utilizando-a-api/obter-detalhes-do-merchant). |
| `403 Forbidden` | `partnerId` fora do alcance do token. |
| `422 Unprocessable Content` | Dados inválidos. O `title` traz os erros por campo, com os nomes internos em snake\_case. |
