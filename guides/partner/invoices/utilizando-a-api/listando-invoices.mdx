title: Listando faturas
description: Liste a fatura do mês de cada loja, diretas e de revendas, com os blocos de preço a pagar e a receber.
icon: list
---

`GET /partner/v2/{partnerId}/invoices` devolve uma fatura por loja para o mês consultado.

| `partnerId` | Lojas na resposta |
| --- | --- |
| ID do parceiro | Todas: as atendidas diretamente e as das revendas (essas com `resaleId`). |
| ID de uma revenda | Só as lojas da revenda. Preços na visão da revenda. |

Um token de parceiro aceita o próprio ID e o de qualquer revenda dele; um token de revenda, só o da revenda.

| Status | Quando |
| --- | --- |
| `200 OK` | Lista de faturas. |
| `204 No Content` | Nenhuma fatura no período (por exemplo, mês ainda não fechado). |
| `403 Forbidden` | `partnerId` fora do alcance do token. |

## Requisição

<ParamField path="partnerId" type="uuid" required>ID do parceiro ou de uma revenda.</ParamField>
<ParamField query="year" type="integer">Ano. Sem ele, vale o ano corrente.</ParamField>
<ParamField query="month" type="integer">Mês, de 1 a 12. Sem ele, vale o mês corrente.</ParamField>

<CodeGroup>
```bash cURL
curl 'https://api.deliveryvip.com.br/partner/v2/{partnerId}/invoices?year=2025&month=4' \
  --header 'Authorization: Bearer {token}'
```

```js Node.js
const response = await fetch(
  `https://api.deliveryvip.com.br/partner/v2/${partnerId}/invoices?year=2025&month=4`,
  { headers: { Authorization: `Bearer ${token}` } },
)
const invoices = response.status === 204 ? [] : await response.json()

const payable = (prices) => prices?.find((price) => price.type === 'PAYABLE')
```

```python Python
response = requests.get(
    f"https://api.deliveryvip.com.br/partner/v2/{partner_id}/invoices",
    params={"year": 2025, "month": 4},
    headers={"Authorization": f"Bearer {token}"},
)
invoices = [] if response.status_code == 204 else response.json()

def payable(prices):
    return next((p for p in prices or [] if p["type"] == "PAYABLE"), None)
```
</CodeGroup>

`RECEIVABLE` só vem quando a tabela de preços de recebíveis está habilitada para o parceiro. Procure os blocos pelo `type`, nunca pela posição. Consultando com o ID de uma revenda e sem essa tabela, as faturas vêm sem `totalPrice` e os itens sem preço.
</Warning>
