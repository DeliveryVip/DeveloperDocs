Depois de cada polling com resultados, envie o acknowledgment dos eventos recebidos. É o mesmo endpoint dos eventos de pedidos: um lote pode misturar eventos de pedido e de indoor, e você confirma todos na mesma chamada.

## Requisição

<ParamField body="id" type="uuid" required>
O `eventId` de cada evento recebido. O corpo é um **array** de objetos, um por evento.
</ParamField>

<Warning>
O campo lido é `id`. Reenviar o evento como veio do polling não funciona: ele traz o identificador em `eventId`, e a API não o reconhece. Monte o corpo como `[{ "id": evento.eventId }]`.
</Warning>

<CodeGroup>
```bash cURL
curl --request POST 'https://api.deliveryvip.com.br/merchant/v3/events/acknowledgment' \
  --header 'Authorization: Bearer {token}' \
  --header 'Content-Type: application/json' \
  --data '[
    { "id": "78b58a39-e222-44a4-a2c4-083c4837ed7d" },
    { "id": "b99a3643-b6a5-408f-9f2f-29a1a6cc3cec" }
  ]'
```

```js Node.js
await fetch('https://api.deliveryvip.com.br/merchant/v3/events/acknowledgment', {
  method: 'POST',
  headers: { Authorization: `Bearer ${token}`, 'Content-Type': 'application/json' },
  body: JSON.stringify(events.map(({ eventId }) => ({ id: eventId }))),
})
```

```python Python
requests.post(
    "https://api.deliveryvip.com.br/merchant/v3/events/acknowledgment",
    headers={"Authorization": f"Bearer {token}"},
    json=[{"id": event["eventId"]} for event in events],
)
```
</CodeGroup>

## Resposta

<ResponseField name="total" type="integer">
Quantos eventos foram confirmados nesta chamada.
</ResponseField>

```json 202 Accepted
{ "total": 2 }
```

## Boas práticas

<Check>
**Um acknowledgment por polling com resultados.** Confirme o lote inteiro de uma vez.
</Check>

<Check>
**Confirme também o que você não usa.** Se a sua integração ainda não trata `CALL_WAITER` ou `CLOSE_ACCOUNT`, confirme esses eventos mesmo assim, ou eles voltam em todo polling e ocupam espaço no lote de 100.
</Check>

<Check>
**Pode repetir sem medo.** A operação é idempotente: confirmar o mesmo evento duas vezes não gera erro.
</Check>
