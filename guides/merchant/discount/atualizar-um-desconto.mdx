---
title: Atualizar um desconto
description: Altere o valor, o período ou as regras de um desconto existente.
icon: pen
---

Altera um desconto. Os campos são os mesmos do [cadastro](/guides/merchant/discount/adicionar-um-desconto#requisição), todos opcionais: envie só o que quer mudar. O que não for enviado fica como está.

<Info>
**Opções na atualização.** Sem `options` no corpo, as opções atuais ficam como estão. Com `options`, a lista enviada substitui a atual: uma opção que não estiver nela é desligada, e `"options": []` desliga todas.
</Info>

<Info>
Para ligar ou desligar o desconto agora, use as [ações](/guides/merchant/discount/acoes-dos-descontos) em vez de mexer nas datas. `status` é ignorado se enviado.
</Info>

## Requisição

<ParamField path="merchantId" type="uuid" required>
A loja.
</ParamField>

<ParamField path="discountId" type="uuid" required>
O `id` do desconto.
</ParamField>

<ParamField body="type" type="string">
`SMART` ou `COUPON`.
</ParamField>

<ParamField body="name" type="string">
Nome do desconto `SMART`.
</ParamField>

<ParamField body="code" type="string">
Código do cupom `COUPON`.
</ParamField>

<ParamField body="startsAt" type="datetime">
A partir de quando o desconto vale.
</ParamField>

<ParamField body="endsAt" type="datetime">
Até quando o desconto vale.
</ParamField>

<ParamField body="rules" type="object">
Envie só as regras que mudam.

<Expandable title="propriedades">
<ParamField body="value" type="number">
Valor do desconto.
</ParamField>
<ParamField body="valueType" type="string">
`PERCENTAGE` ou `FIXED_AMOUNT`.
</ParamField>
<ParamField body="discountType" type="string">
`SUBTOTAL`, `TOTAL` ou `DELIVERY`.
</ParamField>
<ParamField body="minimumOrderValue" type="number">
Valor mínimo dos produtos na sacola.
</ParamField>
<ParamField body="usageLimit" type="integer">
Limite total de usos. `0` é ilimitado.
</ParamField>
<ParamField body="usagePerCustomer" type="string">
`MANY`, `ONCE` ou `FIRST_ORDER`.
</ParamField>
</Expandable>
</ParamField>

<ParamField body="options" type="string[]">
Lista completa de opções: `NON_PROMOTION_PRODUCTS` e, só em `COUPON`, `CUMULATIVE_WITH_SMART`. Substitui a lista atual; omita para manter.
</ParamField>

<CodeGroup>
```bash cURL
curl --request PATCH 'https://api.deliveryvip.com.br/merchant/v3/{merchantId}/discounts/{discountId}' \
  --header 'Authorization: Bearer {token}' \
  --header 'Content-Type: application/json' \
  --data '{
    "rules": { "value": 15 },
    "options": ["NON_PROMOTION_PRODUCTS"]
  }'
```

```js Node.js
const response = await fetch(
  `https://api.deliveryvip.com.br/merchant/v3/${merchantId}/discounts/${discountId}`,
  {
    method: 'PATCH',
    headers: { Authorization: `Bearer ${token}`, 'Content-Type': 'application/json' },
    body: JSON.stringify({ rules: { value: 15 }, options: ['NON_PROMOTION_PRODUCTS'] }),
  },
)
const discount = await response.json()
```

```python Python
response = requests.patch(
    f"https://api.deliveryvip.com.br/merchant/v3/{merchant_id}/discounts/{discount_id}",
    headers={"Authorization": f"Bearer {token}"},
    json={"rules": {"value": 15}, "options": ["NON_PROMOTION_PRODUCTS"]},
)
discount = response.json()
```
</CodeGroup>

## Resposta

Retorna `200 OK` com o [objeto desconto](/guides/merchant/discount/obter-detalhes-do-desconto#resposta) atualizado.

```json 200 OK
{
  "id": "4572126a-6161-4b68-af04-3cb2fb4fa7a5",
  "createdAt": "2024-08-01T19:43:15-03:00",
  "startsAt": "2024-04-28T17:18:00-03:00",
  "type": "SMART",
  "name": "Desconto 10%",
  "status": "ACTIVE",
  "rules": {
    "valueType": "PERCENTAGE",
    "value": 15.0,
    "minimumOrderValue": 32.0,
    "usageLimit": 0,
    "usagePerCustomer": "MANY",
    "discountType": "SUBTOTAL"
  },
  "options": ["NON_PROMOTION_PRODUCTS"]
}
```

<Info>
A atualização não mexe nos canais de venda. Se o desconto também estava ligado a outros canais pelo painel, como um marketplace, eles continuam ligados.
</Info>

## Erros

| Status | Quando |
| --- | --- |
| `403 Forbidden` | A loja não contratou o módulo de descontos. |
| `404 Not Found` | O `merchantId` não autorizou o seu app, ou o desconto não existe ou foi removido. |
| `422 Unprocessable Content` | O resultado da alteração é inválido, pelas mesmas regras do [cadastro](/guides/merchant/discount/adicionar-um-desconto#erros). O `title` traz os campos com problema. |
