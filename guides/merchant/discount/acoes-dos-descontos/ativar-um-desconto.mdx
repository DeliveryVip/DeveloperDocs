---

Ativa o desconto na hora: `startsAt` passa a ser o momento da chamada e `endsAt` é apagado. O `status` vira `ACTIVE` e o desconto vale até ser desativado ou ganhar uma nova data de fim.

Use para reativar um desconto vencido ou desativado, ou para antecipar um desconto agendado.

<Warning>
A data de fim é apagada. Se o desconto precisa terminar numa data, [atualize](/guides/merchant/discount/atualizar-um-desconto) `endsAt` depois de ativar.
</Warning>

## Requisição

<ParamField path="merchantId" type="uuid" required>
A loja.
</ParamField>

<ParamField path="discountId" type="uuid" required>
O `id` do desconto.
</ParamField>

<CodeGroup>
```bash cURL
curl --request POST 'https://api.deliveryvip.com.br/merchant/v3/{merchantId}/discounts/{discountId}/available' \
  --header 'Authorization: Bearer {token}'
```

```js Node.js
const response = await fetch(
  `https://api.deliveryvip.com.br/merchant/v3/${merchantId}/discounts/${discountId}/available`,
  { method: 'POST', headers: { Authorization: `Bearer ${token}` } },
)
const discount = await response.json()
```

```python Python
response = requests.post(
    f"https://api.deliveryvip.com.br/merchant/v3/{merchant_id}/discounts/{discount_id}/available",
    headers={"Authorization": f"Bearer {token}"},
)
discount = response.json()
```
</CodeGroup>

## Erros

| Status | Quando |
| --- | --- |
| `403 Forbidden` | A loja não contratou o módulo de descontos. |
| `404 Not Found` | O `merchantId` não autorizou o seu app, ou o desconto não existe ou foi removido. |
