---

Encerra o desconto na hora: `startsAt` e `endsAt` passam a ser o momento da chamada. O `status` vira `OVERDUE` e o desconto deixa de ser aplicado em novos pedidos, mas continua na listagem e com as [estatísticas](/guides/merchant/discount/obter-estatistica-do-desconto) disponíveis.

Use para pausar uma campanha. Para voltar, [ative](/guides/merchant/discount/acoes-dos-descontos/ativar-um-desconto) o desconto de novo.

<Info>
As datas originais são sobrescritas. Depois de desativado, `startsAt` não mostra mais quando a campanha começou de fato.
</Info>

## Requisição

<ParamField path="merchantId" type="uuid" required>
A loja.
</ParamField>

<ParamField path="discountId" type="uuid" required>
O `id` do desconto.
</ParamField>

<CodeGroup>
```bash cURL
curl --request POST 'https://api.deliveryvip.com.br/merchant/v3/{merchantId}/discounts/{discountId}/unavailable' \
  --header 'Authorization: Bearer {token}'
```

```js Node.js
const response = await fetch(
  `https://api.deliveryvip.com.br/merchant/v3/${merchantId}/discounts/${discountId}/unavailable`,
  { method: 'POST', headers: { Authorization: `Bearer ${token}` } },
)
const discount = await response.json()
```

```python Python
response = requests.post(
    f"https://api.deliveryvip.com.br/merchant/v3/{merchant_id}/discounts/{discount_id}/unavailable",
    headers={"Authorization": f"Bearer {token}"},
)
discount = response.json()
```
</CodeGroup>

## Erros

| Status | Quando |
| --- | --- |
| `403 Forbidden` | A loja não contratou o módulo de descontos. |
| `404 Not Found` | O `merchantId` não autorizou o seu app, ou o desconto não existe ou foi removido. |
