---
title: Adicionar um desconto
description: Cadastre um desconto automático ou um cupom, com valor, período e regras de uso.
icon: plus
---

Cadastra um desconto na loja. O desconto passa a valer em `startsAt` e vale só no canal de venda da própria loja.

## Requisição

<ParamField path="merchantId" type="uuid" required>
A loja.
</ParamField>

<ParamField body="type" type="string" required>
`SMART` (automático) ou `COUPON` (cupom). Veja [tipos de desconto](/guides/merchant/discount#tipos-de-desconto).
</ParamField>

<ParamField body="name" type="string">
Nome do desconto. **Obrigatório quando `type` é `SMART`.**
</ParamField>

<ParamField body="code" type="string">
Código que o cliente digita. **Obrigatório quando `type` é `COUPON`.** Só letras e números, sem espaços, e único entre os cupons não removidos da loja, sem diferenciar maiúsculas de minúsculas.
</ParamField>

<ParamField body="startsAt" type="datetime" required>
A partir de quando o desconto vale. Uma data no futuro deixa o desconto `SCHEDULED`.
</ParamField>

<ParamField body="endsAt" type="datetime">
Até quando o desconto vale. Precisa ser depois de `startsAt`. Sem ele, o desconto não expira.
</ParamField>

<ParamField body="rules" type="object" required>
Regras de valor e de uso.

<Expandable title="propriedades">
<ParamField body="value" type="number" required>
Valor do desconto, maior que zero. Em `PERCENTAGE`, no máximo `100`.
</ParamField>
<ParamField body="valueType" type="string" default="PERCENTAGE">
`PERCENTAGE` (porcentagem) ou `FIXED_AMOUNT` (valor em reais).
</ParamField>
<ParamField body="discountType" type="string" default="TOTAL">
Sobre o que o desconto incide: `SUBTOTAL` (soma dos produtos), `TOTAL` (produtos mais entrega) ou `DELIVERY` (só a entrega).
</ParamField>
<ParamField body="minimumOrderValue" type="number" default="0">
Valor mínimo dos produtos na sacola para o desconto valer. `0` não exige mínimo.
</ParamField>
<ParamField body="usageLimit" type="integer" default="0">
Quantas vezes o desconto pode ser usado no total, somando todos os clientes. `0` é ilimitado.
</ParamField>
<ParamField body="usagePerCustomer" type="string" default="ONCE">
`MANY` (qualquer cliente, quantas vezes quiser), `ONCE` (uma vez por cliente) ou `FIRST_ORDER` (só no primeiro pedido do cliente na loja).
</ParamField>
</Expandable>
</ParamField>

<ParamField body="options" type="string[]">
Opções extras:

- `NON_PROMOTION_PRODUCTS`: o desconto só incide sobre produtos que não estão em promoção, e o mínimo do pedido considera só esses produtos.
- `CUMULATIVE_WITH_SMART`: o cupom se soma ao desconto automático em vez de substituí-lo. **Só para `COUPON`**: em `SMART`, a API responde `422`.
</ParamField>

<Info>
`status` não é aceito e é ignorado se enviado: ele é calculado a partir das datas. Veja [status](/guides/merchant/discount#status).
</Info>

## Resposta

Retorna `200 OK` com o [objeto desconto](/guides/merchant/discount/obter-detalhes-do-desconto#resposta).

```json 200 OK
{
  "id": "4572126a-6161-4b68-af04-3cb2fb4fa7a5",
  "createdAt": "2024-04-20T19:43:15-03:00",
  "startsAt": "2024-05-01T00:00:00-03:00",
  "endsAt": "2024-05-31T23:59:59-03:00",
  "type": "COUPON",
  "code": "BEMVINDO10",
  "status": "SCHEDULED",
  "rules": {
    "valueType": "PERCENTAGE",
    "value": 10.0,
    "minimumOrderValue": 50.0,
    "usageLimit": 100,
    "usagePerCustomer": "FIRST_ORDER",
    "discountType": "SUBTOTAL"
  },
  "options": ["CUMULATIVE_WITH_SMART"]
}
```

## Erros

Em `422`, o `title` traz os campos com problema e as mensagens de validação.

```json 422 Unprocessable Content
{
  "status": "422",
  "title": { "code": ["has already been taken"] }
}
```

| Status | Quando |
| --- | --- |
| `403 Forbidden` | A loja não contratou o módulo de descontos. |
| `404 Not Found` | O `merchantId` não autorizou o seu app. |
| `422 Unprocessable Content` | `type` ausente ou inválido, `name` ou `code` faltando, `code` repetido ou com espaços, `value` zero ou acima de 100% em `PERCENTAGE`, `endsAt` antes de `startsAt`, `CUMULATIVE_WITH_SMART` num `SMART`. |
