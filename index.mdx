## Merchant API ou Open Delivery?

Os dois caminhos levam os pedidos da DeliveryVip até o seu PDV. A diferença está no padrão que o seu sistema fala.

| | Merchant API (V3) | Open Delivery |
| --- | --- | --- |
| **Padrão** | API própria da DeliveryVip | Especificação aberta da Abrasel (Order `1.3.0`, Merchant `1.0.0`) |
| **Host** | `api.deliveryvip.com.br` | `od.deliveryvip.com.br` |
| **Credenciais** | `client_id` e `client_secret` do app; o mesmo token atende todas as lojas que instalaram o app | `client_id` do app e um `client_secret` por loja; cada token vale para uma loja |
| **Eventos** | Webhook ou polling | Webhook ou polling |
| **Catálogo** | Você envia pela API (update, upsert e force) | Você expõe um endpoint de catálogo no padrão OD e a DeliveryVip importa |
| **Escolha se** | Você está construindo a integração do zero | Seu PDV já implementa Open Delivery para outras plataformas |

<Info>
A **Fidelidade** é uma extensão de app: o operador usa a Merchant API para ativar o programa e ler os pedidos, e implementa as rotas que a DeliveryVip chama no checkout.
</Info>
