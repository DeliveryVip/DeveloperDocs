As listagens que podem crescer muito devolvem os resultados em páginas. A paginação é por **cursor**: cada resposta diz, nos headers, qual valor usar para buscar a próxima página ou a anterior.

<Info>
**Onde vale:** `GET /merchant/v3/{merchantId}/orders` e `GET /merchant/v3/{merchantId}/discounts`. As listagens da Partner API V2 não são paginadas, e o polling de eventos tem a própria regra de lote (até 100 eventos, veja [Consultar novos pedidos](/guides/merchant/order/fluxo-de-integracao/consultar-novos-pedidos)).
</Info>

## Como funciona

<Steps>
<Step title="Busque a primeira página">
Chame a listagem sem cursor. Os resultados vêm do **mais recente para o mais antigo**, 30 por página.
</Step>
<Step title="Leia os headers">
Se houver mais páginas, a resposta traz `X-Next-Cursor` (e `X-Previous-Cursor` a partir da segunda página), além do header `Link` com as URLs prontas.
</Step>
<Step title="Peça a próxima página">
Repita a chamada com `?next={X-Next-Cursor}`, ou siga a URL `rel="next"` do `Link`. Quando a resposta não trouxer `X-Next-Cursor`, você chegou ao fim.
</Step>
</Steps>

## Parâmetros

<ParamField query="next" type="string">
Valor de `X-Next-Cursor` da resposta anterior. Traz a página seguinte.
</ParamField>
<ParamField query="previous" type="string">
Valor de `X-Previous-Cursor`. Traz a página anterior. Não envie junto com `next`: a combinação retorna `400 Bad Request`.
</ParamField>
<ParamField query="per_page" type="integer" default="30">
Itens por página, entre **30 e 250**. Valores fora da faixa são ajustados para o limite mais próximo (`per_page=10` devolve 30 itens).
</ParamField>

Mantenha os mesmos filtros e o mesmo `per_page` em todas as páginas da mesma consulta. As URLs do header `Link` já fazem isso por você.

## Headers da resposta

<ResponseField name="X-Next-Cursor" type="string">
Cursor da próxima página. Ausente na última página.
</ResponseField>
<ResponseField name="X-Previous-Cursor" type="string">
Cursor da página anterior. Ausente na primeira página.
</ResponseField>
<ResponseField name="Link" type="string">
As mesmas páginas como URLs completas, com `rel="next"` e `rel="prev"`. Ausente quando tudo cabe em uma página.
</ResponseField>

Use `--include` no cURL para ver os headers:

```bash
curl --include 'https://api.deliveryvip.com.br/merchant/v3/{merchantId}/orders?per_page=50' \
  --header 'Authorization: Bearer {token}'
```

```http Headers da resposta
HTTP/1.1 200 OK
X-Next-Cursor: WyIyMDI2LTEwLTI4VDE4OjQwOjEyLjAwMC0wMzowMCIsIjY0OTM5ODQyIl0=
X-Previous-Cursor: WyIyMDI2LTEwLTI5VDA5OjEyOjMwLjAwMC0wMzowMCIsIjFjMmY2YTRlIl0=
Link: <https://api.deliveryvip.com.br/merchant/v3/{merchantId}/orders?per_page=50&next=WyIy...>; rel="next", <https://api.deliveryvip.com.br/merchant/v3/{merchantId}/orders?per_page=50&previous=WyIy...>; rel="prev"
```

<Warning>
Trate o cursor como **opaco**: use o valor exatamente como veio, sem decodificar nem montar o seu. Na query, ele precisa estar codificado para URL (o `=` do final vira `%3D`). As bibliotecas de HTTP fazem isso quando você passa o valor como parâmetro.
</Warning>

## Percorrendo todas as páginas

<CodeGroup>
```bash cURL
# primeira página
curl --include 'https://api.deliveryvip.com.br/merchant/v3/{merchantId}/orders?starts_at=2026-10-01' \
  --header 'Authorization: Bearer {token}'

# próxima página, com o X-Next-Cursor recebido
curl --include --get 'https://api.deliveryvip.com.br/merchant/v3/{merchantId}/orders' \
  --data-urlencode 'starts_at=2026-10-01' \
  --data-urlencode 'next={cursor}' \
  --header 'Authorization: Bearer {token}'
```

```js Node.js
async function listAllOrders(merchantId, token) {
  const orders = []
  let cursor = null

  do {
    const url = new URL(`https://api.deliveryvip.com.br/merchant/v3/${merchantId}/orders`)
    url.searchParams.set('per_page', '100')
    if (cursor) url.searchParams.set('next', cursor)

    const response = await fetch(url, { headers: { Authorization: `Bearer ${token}` } })
    if (response.status === 204) break
    orders.push(...(await response.json()))
    cursor = response.headers.get('x-next-cursor')
  } while (cursor)

  return orders
}
```

```python Python
def list_all_orders(merchant_id, token):
    orders, cursor = [], None
    while True:
        params = {"per_page": 100}
        if cursor:
            params["next"] = cursor
        response = requests.get(
            f"https://api.deliveryvip.com.br/merchant/v3/{merchant_id}/orders",
            headers={"Authorization": f"Bearer {token}"},
            params=params,
        )
        if response.status_code == 204:
            break
        orders.extend(response.json())
        cursor = response.headers.get("X-Next-Cursor")
        if not cursor:
            break
    return orders
```
</CodeGroup>

<Note>
Uma listagem **sem resultados** responde `204 No Content`, sem corpo e sem headers de paginação.
</Note>
