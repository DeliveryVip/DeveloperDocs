## Em resumo

| Tema | Regra |
| --- | --- |
| Host | `https://api.deliveryvip.com.br` (Open Delivery: `https://od.deliveryvip.com.br`) |
| Autenticação | `Authorization: Bearer {token}`, token OAuth2 válido por 24 horas |
| Formato | JSON; `204 No Content` sem corpo quando não há resultado |
| Erros | `{ "status": "422", "title": "..." }`, com exceções para `401`, `403` e o endpoint de token |
| Datas | RFC 3339 com offset (`-03:00` ou `Z`) |
| Ambiente | Só produção; testes em uma loja de teste pedida no [Discord](https://discord.gg/AJF8Yha4) |
